# Mila Moodboard

### Creative & Digital Studio

**Creative ideas. Beautiful digital experiences.**

Mila Moodboard is a creative and digital studio website designed to showcase digital services, branding concepts, website designs, and creative projects.

The website combines an elegant feminine aesthetic with a clean, modern and responsive design.

## ✨ Features

- Elegant and responsive design
- Home page with studio introduction
- About section
- Digital services showcase
- Portfolio with project category filters
- Packages and pricing section
- Moodboard Journal
- Contact and inquiry form
- Newsletter subscription section
- Dark Mode and Light Mode
- Theme preference saved using Local Storage
- Smooth scrolling and animations
- Mobile-friendly navigation

## 🎨 Design

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the website in your browser.

No installation or additional dependencies are required.
